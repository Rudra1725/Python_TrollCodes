# 💣 Prank_ur_friend

A chaotic little prank project designed to surprise your friends with unexpected websites, funny sound effects, and over-the-top jump scares. 😂💀

## 🤡 Features

- 🌐 Opens multiple websites for maximum chaos.
- 🔊 Funny voice effects and unexpected sounds.
- 😂 Random surprises to confuse your friends.
- 💻 Packaged as a Windows `.exe` for easy launching.
- 💥 Nuclear-level prank energy (your PC might survive, your peace won't).

## ⚙️ How It Works

Run the application and let the chaos begin! Depending on the configuration, it can open selected websites and play funny sound effects.

## 🚀 Getting Started

1. Download or clone this repository.
2. Run the Python script or build the executable.
3. Configure the websites and sound effects.
4. Test everything before sharing it with your friends.

## ⚠️ Disclaimer

This project is intended for harmless entertainment and educational purposes only.

- Use it only on devices where you have permission.
- Avoid malicious websites, forced downloads, or anything that could damage a device or compromise someone's privacy.
- Let users close the application and stop the sounds easily.

**Built for laughs, not for actual destruction.** 💀😂
